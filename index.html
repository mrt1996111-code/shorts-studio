Shorts Studio Uploader

A private, single-user tool that publishes the owner's own original, self-produced educational Shorts (geography, science and quiz videos) to the owner's own channel.

Uses YouTube API Services

This tool uses the YouTube Data API v3 (videos.insert) to upload videos to the owner's own YouTube channel. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy and this tool's Privacy Policy.

What it does

  • The owner renders original videos on their own computer (3D animation, synthesized sound, text-to-speech narration).
  • The tool signs in once with Google OAuth 2.0, requesting only the youtube.upload scope.
  • It uploads each finished video with its title, description and tags, optionally scheduled with publishAt.
  • It does not read, collect, analyse or store any YouTube data about other users or channels.

Who can use it

Only the owner of this project, for their own channel. It is not offered to the public and has no other users.

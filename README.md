# Shorts Studio Uploader

Private single-user tool that uploads the owner's own original Shorts to the owner's own channel with the YouTube Data API (`youtube.upload` scope only).

- Site: https://mrt1996111-code.github.io/shorts-studio/
- Privacy Policy: https://mrt1996111-code.github.io/shorts-studio/privacy.html
- Terms: https://mrt1996111-code.github.io/shorts-studio/terms.html
- Upload script: `upload_script.py` (Python standard library only; credentials are read from local files and are not part of this repository)

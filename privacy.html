Privacy Policy

Last updated: 17 November 2026

1. YouTube API Services

Shorts Studio Uploader ("the tool") uses YouTube API Services. By using the tool you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (http://www.google.com/policies/privacy).

2. What information the tool accesses

  • When the owner signs in with Google OAuth 2.0, Google returns an access token and a refresh token for the https://www.googleapis.com/auth/youtube.upload scope. This is the only scope requested.
  • The tool sends the owner's own video files and their title, description, tags and publishing time to the YouTube Data API.
  • The tool receives the ID and status of each uploaded video, to confirm the upload.

The tool does not access, collect or process any information about other YouTube users, viewers, channels, comments or analytics.

3. How the information is used

Tokens are used only to upload the owner's videos to the owner's channel. The video ID is used only to show the owner a link to the uploaded video.

4. How the information is stored

The refresh token is stored only on the owner's own computer, in a file readable only by the owner's user account. Upload results (video ID, link, date) are kept in a local log on the same computer. Nothing is stored on any server operated by the tool, and no cookies or tracking technologies are used by this website or the tool.

5. Sharing

No information is sold, shared with or disclosed to any third party. Data is sent only to Google/YouTube through the YouTube Data API in order to perform the upload.

6. Revoking access and deleting data

  • Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions.
  • When access is revoked, or on request, the stored token and the local upload log are deleted within 7 days.
  • Any data obtained from the API is refreshed or deleted in line with the YouTube API Services Developer Policies (stored API data is not kept longer than 30 days without being refreshed).

7. Contact

Questions about this policy: open an issue at github.com/mrt1996111-code/shorts-studio/issues.
